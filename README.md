Garage Manager
Overview
As a software engineer, I'm always looking for new ways to improve my skills. I work on my car a lot, so I decided to make a program that creates, stores, and loads my car maintenance records. 

Garage Manager is a console-based application that users can use to add their vehicles and add maintenance information. They can add vehicles to their garage, record maintenance like oil changes and repairs, look at the car's maintenance history, and save or load that data from a file.

I created this software was to practice my C++ while building something that is useful to me. I work on my own cars and need a good way to keep track of maintenance history, dates, and repair costs. This project let me make something that is useful to me while supporting both my programming work and my car work.
